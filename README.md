# Go‑Long 🏈
A tiny browser‑based football dodging game built with vanilla JavaScript, HTML, and CSS.

Play it live: https://go-long.vercel.app

---

## Overview
Go‑Long is a lightweight arcade-style browser game where you dodge defenders while running downfield.  
The project is intentionally simple — no frameworks, no build tools — just pure front‑end code.

---

## Features
- Player movement with keyboard controls  
- Basic collision detection  
- Simple game loop in vanilla JS  
- Responsive layout  
- Zero dependencies  

---

## Tech Stack
- **JavaScript** — game logic  
- **HTML** — structure  
- **CSS** — styling  

---

## Project Structure
```
├── assets/                # Game assets (images, sprites)
├── collision-system.js    # Collision detection logic
├── game.js                # Main game loop
├── index.html             # Entry point
└── style.css              # Styling
```
---

## Getting Started

### Run locally
1. Clone the repo:
   ```bash
   git clone https://github.com/santa512/go-long
   ```

2. Open index.html in your browser.
  No build step required — the game runs entirely on vanilla JavaScript, HTML and CSS.

## Deployment
The project is deployed on Vercel.

To redeploy:
- Push to the main branch
- Vercel automatically rebuilds and updates the live site
